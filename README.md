# Justice Hemming — Portfolio

Responsive single-page portfolio built with HTML and CSS.

## Local preview
Open `index.html` in a browser.

## Cloudflare Pages
Connect this repository to a Pages project using Git integration. Select `main` as the production branch, no framework preset, no build command, and `.` as the build output directory. Deploy.

## Content updates
Edit `index.html`. Replace the typographic project covers with approved screenshots when available. Add the verified LinkedIn URL and a public contact method before sharing with employers.
