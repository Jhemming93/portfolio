# Justice Hemming — Portfolio

Responsive single-page portfolio built with HTML and CSS.

## Local preview
Open `public/index.html` in a browser.

## Cloudflare Workers
Connect the repository to a Workers project on `main`. Leave the build command blank and set the deploy command to `npx wrangler deploy`. The `wrangler.jsonc` configuration serves only the `public` directory. Disable preview builds if not needed.

## Content updates
Edit `public/index.html` (the deployed page); keep the root `index.html` copy synchronized if using it for local preview. Add approved project screenshots, verified LinkedIn URL and a public contact method before sharing with employers.
