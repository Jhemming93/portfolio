Interactive web application

Scout the Elf

A holiday hidden-object game designed for short, timed challenges.

View Project

Project background

The project explores how a simple seasonal activity can encourage participation through daily challenges and friendly competition.

Player experience

Players find a hidden character in an image. A timer tracks their performance, incorrect selections incur a time penalty, and leaderboards compare results.

Development approach

The application uses React and TypeScript with Cloudflare hosting. Administrative tools support managing the game and its challenges.

  • React
  • TypeScript
  • Cloudflare

Design priorities

A clear interface, simple interactions and accessible controls are priorities for a game intended to be played on different devices.
